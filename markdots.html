markdots

Hyprland · Arch Linux · pywal16 · MIT

markdots is my dotfiles repo: the configs for the Hyprland desktop I use every day on Arch Linux. The whole setup takes its colours from the current wallpaper, so changing the background restyles the bar, launcher and terminal together.

What's in it

  • Hyprland, a tiling Wayland compositor, with hyprlock and hypridle for locking and idle
  • Kitty terminal and Zsh, using JetBrains Mono
  • Waybar status bar, Wofi launcher and Mako notifications
  • cliphist for clipboard history and awww for wallpapers
  • Extras: fastfetch, btop, cmatrix and asciiquarium

Theming

pywal16 generates a colour scheme from the wallpaper, and Waybar and Wofi import the generated colours. Drop in a new wallpaper, run wal, and everything follows.

Keybinds

SUPER is the main modifier. A few examples: SUPER+Q opens the terminal, SUPER+A opens the launcher, SUPER+L locks the screen, and SUPER+SHIFT+S takes a region screenshot.

Try it

git clone https://github.com/markart25/markdots
cd markdots
cp -r .config/* ~/.config/
wal -i ~/.config/wallpapers

These configs are personal, so expect to tweak a few things: set your monitor scale in monitors.conf and change the hard-coded home path in the Waybar and Wofi CSS imports. Back up your existing dotfiles first.
